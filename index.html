Inventory

Simulates a live ERP/WMS feed of what's occupying each storage location. Export the current location list, then in Excel fill in a Part Number and Quantity next to each occupied location (and an LPN, if it's palletized), and import it back. LPN is optional and controls how a location renders in the 3D view: give it an LPN and it shows up as a single palletized unit load; leave LPN blank and it shows up as loose boxes piled in the location instead. For a mixed pallet carrying more than one part number, add extra rows with the same Location Code and LPN, one row per part number — a location can hold one pallet, or any number of loose-box rows, but not both. The export also includes a Barcode column (pre-filled with the location code, or its current barcode) — edit it and re-import to bulk-update location barcodes, independent of occupancy; a blank cell clears that location's barcode. Re-export any time the rack layout changes, since a location's code depends on its rack/bay/level.

Add Inventory Manually

Quicker than the Export/Import round trip for a one-off change. LPN is optional: fill it in to add (or add another part number to) a palletized unit load — the 3D view shows a pallet; leave it blank to pile loose boxes into the location instead — the 3D view shows individual boxes. A location can hold one pallet, or any number of loose-box entries, but not both — if it already has a pallet, you'll need to use that same LPN (to add to it) or remove the existing entry first.
